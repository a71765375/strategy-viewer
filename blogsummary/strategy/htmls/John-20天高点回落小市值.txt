一、策略思路

小市值策略，追高的基本清零，所以几乎都是找跌多了的博它反弹。反弹时间是短暂的，小市值策略持股天数越少收益越大，就选3D。短期跌得越多，反弹机会越大，就选20天从高点回落幅度作为排序因子。

二、策略描述

20日高点回落幅度、市值二个因子等权排序，过滤掉市值30亿以上的，排除北交所、创业板和科创板。

策略名称：策略

持仓周期：3D

回测时间：2009-01-01到2026-06-12

持股数量：10

使用资金曲线的13日均线作择时，均线向上持仓，均线拐头卖出。

import numpy as np
import pandas as pd

fin_cols = []

def add_factor(df: pd.DataFrame, param, fin_data=None, **kwargs) -> (pd.DataFrame, dict):

    """
    因子说明：从n日内高点回撤幅度
    计算逻辑： (收盘价 - 前高) / (前高 + 1e-8)
    物理意义： 衡量个股在过去n个交易日内从最高点回落的最大幅度。
    """
    n = int(param)
    col_name = kwargs['col_name']
    hh = df['收盘价_复权'].rolling(n).max().shift(1)
    factor_col = (df['收盘价_复权'] - hh) / (hh + 1e-8)

    factor_df = pd.DataFrame({col_name: factor_col}, index=df.index)

    agg_dict = {col_name: 'last'}
    return factor_df, agg_dict

    """
    因子说明：月份
    计算逻辑：
    1. 读取参数中的月份列表（如[1,2,3]代表1-3月），判断交易日期所在月份是否在该列表中。
    2. 若在列表中，则因子值赋为1；否则默认为0。
    
    物理意义：
    中国A股市场存在显著的“日历效应”，如春节前后的“春季躁动”、年末的“基金排名行情”等。该因子捕捉特定月份内市场情绪与资金流动的周期性规律，反映投资者行为反身性导致的收益非对称性。
    """

    col_name = kwargs['col_name']
    # months = list(param)

    factor_col = df['交易日期'].dt.month.isin(param).astype(int)

    factor_df = pd.DataFrame({col_name: factor_col}, index=df.index)

    agg_dict = {col_name: 'last'}

    # 返回新计算的因子列以及因子聚合方式
    return factor_df, agg_dict

"""

微信: xbx8662

"""

import pandas as pd
import numpy as np


def equity_signal(equity_df: pd.DataFrame, *args) -> pd.Series:
    """
    基于净值均线的择时信号，均线向上时持仓，向下空仓
    
    :param equity_df: 资金曲线的DF
    :param args:
        args[0]: 均线天数
    :return: 返回包含 leverage 的数据
    """

    # ===== 获取策略参数
    n = int(args[0])  # 移动平均

    # ===== 计算均线变化
    ma = equity_df["净值"].rolling(n, min_periods=1).mean()
    ma_chg = ma.pct_change()
    
    # 默认持仓
    signals = pd.Series(1.0, index=equity_df.index)
    
    # 均线向下：空仓
    signals.loc[ma_chg<0] = 0.0
    
    return signals

五、总结

对资金曲线用均线再择时，使用的均线天数与资金曲线形状的配合会有差异，这里用13天效果最好，不同策略大概率会是另一个天数。
