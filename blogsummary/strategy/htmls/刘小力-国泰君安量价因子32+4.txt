一、策略思路

延续之前的国泰短期量价因子，内容太多了，电脑算力不够，慢慢的来用

发现32号因子似乎在和其他因子组合中都有不错的结果，所以以它和市值，外加一个因子进行分析

时间选择2018年-现在，因为2015，2017年是极端情况，距离现在太远不具备参考意义，如果只放近3年，又势必会被14下半年，15年的暴涨导致结果太好

二、策略描述

整体还是在小市值中识别反转、确认情绪，并且以与小市值高度相关的指数中证2000来确认持仓信号

1）国泰alpha32——量价相关性

用过去n天的"价格排名与成交量排名"的相关性强度，识别持续追高的风险。我曾经使用过多次不同方式的量价相关性，发现在小市值这种反转形态市场，相关性低（接近0）的股票，在后期会有更好的涨幅，说不清楚为什么，ai告诉我相关性弱表示股票理性上涨（？？为什么），但总归，结果是高度一致的，这个因子作为短期风险警报器，不预测涨跌，只识别"追高程度"。

2）国泰alpha4——一个买卖开关

这是一个二元信号因子（只返回 1 或 -1），核心思想：分层决策 + 价量平衡。

三层判断逻辑：

第一层（绝对优先）：价格超买？

如果 2日均价 > (8日均价 + 8日标准差) → 返回 -1（卖出）
原因：超买是强信号，不管量，先规避

第二层：价格超卖？

如果 2日均价 < (8日均价 - 8日标准差) → 返回 1（买入）
原因：超卖是强信号，不管量，先抄底

第三层（正常区间）：看成交量

如果 今日成交量 ≥ 20日平均成交量 → 返回 1（买入，有资金在布局）
否则 → 返回 -1（卖出，无人问津）
3）指数择时LLT三仓位——我的斜率择时信号

用低延迟趋势线 LLT 跟踪中证 2000 指数，通过斜率判断趋势强弱，实现 0/0.5/1 三档仓位管理，并且在空仓和全仓之间，我增加了一个半仓，实际我实盘中也是如此操作

明确上升趋势 → 满仓 1.0

明确下降趋势 → 空仓 0.0

趋势模糊/震荡 → 半仓 0.5

小市值因子不再赘述

import pandas as pd
import numpy as np

fin_cols = []


def add_factor(df: pd.DataFrame, param=None, **kwargs) -> (pd.DataFrame, dict):
    """
    计算gt_alpha32因子
  
    :param df: 包含'最高价_复权'、'成交量'列
    :param param: tuple (rank_period, corr_period, sum_period) 或单个整数
        - 默认: (20, 3, 3)
    """
    col_name = kwargs['col_name']
  
    # 参数处理
    if param is None:
        rank_period, corr_period, sum_period = 20, 3, 3
    elif isinstance(param, (list, tuple)) and len(param) == 3:
        rank_period, corr_period, sum_period = int(param[0]), int(param[1]), int(param[2])
    elif isinstance(param, (int, float)):
        rank_period = corr_period = sum_period = int(param)
    else:
        raise ValueError(f"参数格式错误: {param}")
  
    # 数据验证
    required_cols = ['最高价_复权', '成交量']
    missing_cols = [col for col in required_cols if col not in df.columns]
    if missing_cols:
        raise ValueError(f"计算因子[gt_alpha32]需要列: {missing_cols}")
  
    # 计算因子
    high = df['最高价_复权']
    volume = df['成交量']
  
    # 1. RANK(HIGH)
    rank_high = high.rolling(window=rank_period, min_periods=rank_period//2).rank(pct=True)
  
    # 2. RANK(VOLUME)
    rank_volume = volume.rolling(window=rank_period, min_periods=rank_period//2).rank(pct=True)
  
    # 3. CORR(RANK(HIGH), RANK(VOLUME), 3)
    corr_values = rank_high.rolling(window=corr_period, min_periods=corr_period).corr(rank_volume)
  
    # 4. RANK(CORR)
    rank_corr = corr_values.rolling(window=rank_period, min_periods=corr_period).rank(pct=True)
  
    # 5. SUM(RANK(CORR), 3)
    sum_rank_corr = rank_corr.rolling(window=sum_period, min_periods=1).sum()
  
    # 6. 取负值
    factor_col = -1 * sum_rank_corr
  
    factor_df = pd.DataFrame({col_name: factor_col}, index=df.index)
    agg_dict = {col_name: 'last'}
  
    return factor_df, agg_dict

import pandas as pd
import numpy as np

# 财务因子列：此列表用于存储财务因子相关的列名称
fin_cols = []  # 无需财务数据


def add_factor(df: pd.DataFrame, param=None, **kwargs) -> (pd.DataFrame, dict):
    """
    计算gt_alpha4因子:
    ((((SUM(CLOSE, long) / long) + STD(CLOSE, long)) < (SUM(CLOSE, short) / short))
      ? -1
      : (((SUM(CLOSE, short) / short) < ((SUM(CLOSE, long) / long) - STD(CLOSE, long)))
          ? 1
          : ((VOLUME / MEAN(VOLUME, volume_period)) >= 1 ? 1 : -1)))

    PDF原文已核对并按原文公式实现，默认(short, long, volume_period)=(2,8,20)。
  
    工作流程:
    1. 计算价格的短期(2日)和长期(8日)均值及标准差
    2. 计算成交量的20日均值
    3. 根据三层嵌套条件进行判断,返回 -1 或 1
  
    :param df: pd.DataFrame, 包含单只股票的K线数据,必须包括'收盘价_复权'、'成交量'列
    :param param: tuple (short_period, long_period, volume_period), 默认为(2, 8, 20)
    :param kwargs: 其他关键字参数,包括:
        - col_name: 新计算的因子列名
    :return: tuple
        - pd.DataFrame: 包含新计算的因子列
        - dict: 聚合方式字典
    """
  
    # ======================== 参数处理 ===========================
    col_name = kwargs['col_name']
  
    # 解析参数: (短期周期, 长期周期, 成交量周期)
    if param is None:
        short_period = 2
        long_period = 8
        volume_period = 20
    elif isinstance(param, (list, tuple)) and len(param) == 3:
        short_period = int(param[0])
        long_period = int(param[1])
        volume_period = int(param[2])
    else:
        # 如果只传一个参数,认为是调整长期周期,短期和成交量周期使用默认值
        long_period = int(param)
        short_period = 2
        volume_period = 20
  
    # ======================== 数据验证 ===========================
    required_cols = ['收盘价_复权', '成交量']
    missing_cols = [col for col in required_cols if col not in df.columns]
    if missing_cols:
        raise ValueError(f"计算因子[gt_alpha4]需要列: {missing_cols}")
  
    # ======================== 计算因子 ===========================
    close = df['收盘价_复权']
    volume = df['成交量']
  
    # 1. 计算价格的均值和标准差
    # SUM(CLOSE, N) / N 等价于 MEAN(CLOSE, N)
    mean_short = close.rolling(window=short_period, min_periods=1).mean()
    mean_long = close.rolling(window=long_period, min_periods=1).mean()
    std_long = close.rolling(window=long_period, min_periods=1).std()
  
    # 2. 计算成交量的均值
    mean_volume = volume.rolling(window=volume_period, min_periods=1).mean()
  
    # 3. 计算相对成交量
    relative_volume = volume / mean_volume
    # 处理除零情况
    relative_volume = relative_volume.fillna(0)
  
    # 4. 计算布林带上轨和下轨
    upper_band = mean_long + std_long  # 8日均价 + 8日标准差
    lower_band = mean_long - std_long  # 8日均价 - 8日标准差
  
    # 5. 三层嵌套判断
    # 第一层: 检查是否超买 (短期均价 > 长期上轨)
    condition1 = upper_band < mean_short
  
    # 第二层: 检查是否超卖 (短期均价 < 长期下轨)
    condition2 = mean_short < lower_band
  
    # 第三层: 检查成交量是否充足 (相对成交量 >= 1)
    condition3 = relative_volume >= 1
  
    # 使用numpy的where进行嵌套条件判断
    # 逻辑: if condition1 then -1 else (if condition2 then 1 else (if condition3 then 1 else -1))
    factor_col = np.where(
        condition1,
        -1,  # 超买 → -1
        np.where(
            condition2,
            1,  # 超卖 → 1
            np.where(
                condition3,
                1,  # 量能充足 → 1
                -1  # 量能不足 → -1
            )
        )
    )
  
    # 转换为Series
    factor_col = pd.Series(factor_col, index=df.index)
  
    # 创建包含指定因子的DataFrame
    factor_df = pd.DataFrame({col_name: factor_col}, index=df.index)
  
    # ======================== 聚合方式 ===========================
    agg_dict = {col_name: 'last'}
  
    return factor_df, agg_dict

指数择时LLT

import os
import pandas as pd
import numpy as np
import config


def _compute_llt(price: pd.Series, d_window: int) -> pd.Series:
    """
    低延迟趋势线 LLT 计算（基于广发研报公式的常见实现版本）

    参数:
    - price: 价格序列（按时间正序，index 为日期）
    - d_window: 等效 EMA / MA 窗口长度 d，用来确定 α

    返回:
    - LLT 序列，index 与 price 一致
    """
    price = price.astype(float)
    # 等效 EMA 的 α，研报中给出 α 与 d 的关系: α = 2 / (d + 1)
    alpha = 2.0 / (d_window + 1.0)

    llt = pd.Series(index=price.index, dtype=float)
    if len(price) == 0:
        return llt
    if len(price) == 1:
        llt.iloc[0] = price.iloc[0]
        return llt

    # 初始化前两点：直接等于价格（简单、稳健的初始化方式）
    llt.iloc[0] = price.iloc[0]
    llt.iloc[1] = price.iloc[1]

    # 常见的 LLT 递推公式：
    # LLT_t = (α - α^2/4) * price_t
    #        + 0.5 * α^2 * price_{t-1}
    #        - (α - 3/4 * α^2) * price_{t-2}
    #        + 2 * (1-α) * LLT_{t-1}
    #        - (1-α)^2 * LLT_{t-2}
    alpha2 = alpha * alpha
    c0 = alpha - alpha2 / 4.0
    c1 = 0.5 * alpha2
    c2 = -(alpha - 3.0 * alpha2 / 4.0)
    c3 = 2.0 * (1.0 - alpha)
    c4 = -(1.0 - alpha) ** 2

    for i in range(2, len(price)):
        p0 = price.iloc[i]
        p1 = price.iloc[i - 1]
        p2 = price.iloc[i - 2]
        y1 = llt.iloc[i - 1]
        y2 = llt.iloc[i - 2]
        llt.iloc[i] = c0 * p0 + c1 * p1 + c2 * p2 + c3 * y1 + c4 * y2

    return llt


def equity_signal(equity_df: pd.DataFrame, *args) -> pd.Series:
    """
    基于广发《低延迟趋势线与交易性择时》研报思想的 LLT 三档仓位择时（只做多版本）：

    - 读取 `csi932000.csv`（GBK，时间列 `candle_end_time`），视为中证2000指数
    - 使用 LLT 低延迟趋势线跟踪该指数的收盘走势
    - 通过 LLT 的“切线斜率”（日差分）判断趋势方向，并设置 0/0.5/1 三档仓位：
      * 满仓 (1.0)：上升趋势足够明确（斜率 > 正向阈值）
      * 空仓 (0.0)：下降趋势足够明确（斜率 < 负向阈值）
      * 半仓 (0.5)：趋势模糊 / 震荡区间（斜率在阈值附近的小幅波动）

    参数:
    - args[0]: d_window，LLT 对应的等效窗口长度 d（正整数，类似“多少日均线”）
    - args[1]: deadband_bp，斜率死区阈值（单位：bp，万分之一）
               例如 5 表示 5bp ≈ 0.05%，用于区分“趋势明确”和“趋势模糊”区间

    返回:
    - 与 `equity_df` 同索引的 Series（float，取值 0.0/0.5/1.0）
    """
    # ===== 参数校验 =====
    if len(args) < 2:
        raise ValueError("LLT 指数择时需要两个参数：d_window, deadband_bp")

    try:
        d_window = int(args[0])
        deadband_bp = int(args[1])
    except Exception as e:
        raise ValueError("d_window 与 deadband_bp 需为可转换为整数的数值") from e

    if d_window <= 0:
        raise ValueError("d_window 必须为正整数")
    if deadband_bp < 0:
        raise ValueError("deadband_bp 不能为负数")

    # 将 deadband 从 bp 转为比例（例如 5bp -> 0.0005）
    deadband = deadband_bp / 10000.0

    # ===== 读取外部指数数据 =====
    index_path = os.path.join(config.index_data_path, "csi932000.csv")
    ext_df = pd.read_csv(index_path, encoding="gbk", parse_dates=["candle_end_time"])

    # 优先使用真实收盘价，如果不存在，则由涨跌幅 pct_chg 还原一个“指数水平”
    price = None
    for col in ["close", "close_price", "close_index", "closePrice"]:
        if col in ext_df.columns:
            price = ext_df[col]
            break

    if price is None:
        if "pct_chg" not in ext_df.columns:
            raise ValueError("外部文件缺少价格信息（未找到 close 相关列，且缺少 pct_chg 列）")
        # 由 pct_chg 构造一个相对价格序列（从 1 起步）
        # pct_chg 为百分比（例如 1.0 表示 1%），这里按常见约定处理
        pct = ext_df["pct_chg"].astype(float) / 100.0
        price = (1.0 + pct).cumprod()

    # 时间索引准备（按时间正序）
    ext_df = ext_df.sort_values("candle_end_time").set_index("candle_end_time")
    price = pd.Series(price.values, index=ext_df.index)

    # ===== 计算 LLT 及斜率 =====
    llt = _compute_llt(price, d_window=d_window)

    # 为了避免除零，先替换 0，再计算相对斜率（类似“日涨跌幅”）
    llt_safe = llt.replace(0, np.nan)
    slope = llt.diff()  # 一阶差分近似切线斜率
    slope_pct = slope / llt_safe.shift(1)

    # 可选：对斜率做一个轻微平滑，减弱日内噪声（这里使用一个温和的 EMA）
    slope_pct_smoothed = slope_pct.ewm(span=max(3, min(d_window // 4, 10)),
                                       adjust=False,
                                       min_periods=1).mean()

    # ===== 三档仓位逻辑 =====
    # 趋势向上且力度超过阈值 → 满仓
    condition_full = slope_pct_smoothed > deadband
    # 趋势向下且力度超过阈值 → 空仓
    condition_empty = slope_pct_smoothed < -deadband

    raw_signal = np.where(
        condition_full,
        1.0,  # 明确上升趋势 → 满仓
        np.where(
            condition_empty,
            0.0,  # 明确下降趋势 → 空仓
            0.5,  # 介于两者之间 → 视为震荡 / 不明确 → 半仓
        ),
    )

    raw_signal = pd.Series(raw_signal, index=ext_df.index)

    # ===== 对齐到 equity_df 的日期轴，并按现有项目习惯补齐 =====
    target_dates = None
    if "交易日期" in equity_df.columns:
        target_dates = pd.to_datetime(equity_df["交易日期"])
    elif np.issubdtype(np.array(equity_df.index).dtype, np.datetime64):
        target_dates = pd.to_datetime(equity_df.index)

    if target_dates is not None:
        # 与现有单指数择时逻辑保持一致：用外部指数信号按日期对齐，缺失用前值填充，
        # 最前段仍缺失时，默认 1.0（即指数信号缺失时不主动减仓）
        aligned = raw_signal.reindex(target_dates).ffill().fillna(1.0)
        signals = pd.Series(aligned.values, index=equity_df.index)
    else:
        # 回退方案：无法按日期对齐时，按长度对齐（前段缺口填 1.0）
        raw_full = raw_signal.ffill().fillna(1.0).to_numpy()
        if len(raw_full) >= len(equity_df):
            values = raw_full[-len(equity_df):]
        else:
            pad = np.ones(len(equity_df) - len(raw_full), dtype=float)
            values = np.concatenate([pad, raw_full])
        signals = pd.Series(values, index=equity_df.index)

    return signals
