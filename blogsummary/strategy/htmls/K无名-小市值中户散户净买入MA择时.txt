一、策略核心思路
选股因子（双因子驱动）：
市值因子 （权重2）：升序排序，偏好小市值股票
中户净买入占比 （权重1，16日参数）：降序排序，偏好中户资金持续流入的股票
过滤条件：
散户净买入占比 ≤ 0：排除散户追涨的股票，避免"接盘"
策略特点

资金博弈视角 ：

跟随"中户"（相对理性的资金）的买入方向
规避"散户"（追涨杀跌资金）的买入行为
本质是寻找"聪明钱"流入、散户未关注的标的
市值偏好 ：
小市值股票流动性好、弹性大
配合资金流向因子，捕捉资金推动的上涨机会

2.1 市值.py
import pandas as pd

fin_cols = []

def add_factor(df: pd.DataFrame, param, fin_data=None, **kwargs) -> (pd.DataFrame, dict):

    """
    因子说明：市值
    计算逻辑：
    1. 优先使用'总市值'列，若不存在则使用'流通市值'列，若两者均不存在则使用默认值1e8
    2. 返回包含该因子值的DataFrame，聚合方式为取最新值

    物理意义：
    市值反映了市场对上市公司整体价值的定价，在中国A股市场中，市值因子与股票预期收益存在显著负相关（小市值效应）。由于A股市场存在显著的散户主导特征和壳价值溢价，小盘股往往具有更高的波动性和投机性，市值因子在量价博弈中体现了市场参与者的反身性定价行为。
    """
    col_name = kwargs['col_name']
    factor_col = df.get("总市值", df.get("流通市值", 1e8))

    factor_df = pd.DataFrame({col_name: factor_col}, index=df.index)

    agg_dict = {col_name: 'last'}
    return factor_df, agg_dict

2.2 中户净买入占比.py

import pandas as pd

fin_cols = []

# 需要额外加载的行情数据列（资金流数据）
ov_cols = ["中户资金买入额", "中户资金卖出额"]


def add_factor(df: pd.DataFrame, param, fin_data=None, **kwargs) -> (pd.DataFrame, dict):

    """
    因子说明：中户净买入占比
    计算逻辑：
    1. 计算中户净买入 = 中户资金买入额 - 中户资金卖出额
    2. 计算中户净买入占比 = 中户净买入 / 成交额
    3. 对过去n天的中户净买入占比进行滚动平均
  
    物理意义：
    衡量中户资金的净买入力度占成交额的比例。根据东吴金工研报，中户资金流在小市值股票中具有正向效应。中户通常指资金量中等的投资者群体，其资金流向具有一定的信息含量。正值表示中户资金净流入，负值表示净流出。该因子可用于捕捉中户资金动向，辅助判断市场情绪。
    """
    col_name = kwargs["col_name"]
    window = param if param else 5

    # 检查必要的列是否存在
    required_cols = [
        "中户资金买入额",
        "中户资金卖出额",
        "成交额",
    ]
    if not all(col in df.columns for col in required_cols):
        # 如果缺少资金流数据，返回NaN
        factor_col = float("nan")
        factor_df = pd.DataFrame({col_name: factor_col}, index=df.index)
        agg_dict = {col_name: 'last'}
        return factor_df, agg_dict

    # 计算中户净买入
    net_buy = df["中户资金买入额"] - df["中户资金卖出额"]

    # 计算占成交额比例
    net_buy_ratio = net_buy / df["成交额"]

    # 滚动平均
    factor_col = net_buy_ratio.rolling(window, min_periods=1).mean()

    factor_df = pd.DataFrame({col_name: factor_col}, index=df.index)

    agg_dict = {col_name: 'last'}
    return factor_df, agg_dict

3、择时因子
移动平均线.py

import pandas as pd


def equity_signal(equity_df: pd.DataFrame, *args) -> pd.Series:
    """
    根据资金曲线，动态调整杠杆
    :param equity_df: 资金曲线的DF
    :param args: 其他参数
    :return: 返回包含 leverage 的数据
    """

    # ===== 获取策略参数
    n = int(args[0])

    # ===== 计算指标
    # 计算均线
    ma = equity_df["净值"].rolling(n, min_periods=1).mean()

    # 默认空仓
    signals = pd.Series(0.0, index=equity_df.index)

    # equity 在均线之上，才持有
    above = equity_df["净值"] > ma
    signals.loc[above] = 1.0

    return signals
