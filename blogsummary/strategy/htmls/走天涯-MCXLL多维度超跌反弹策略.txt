一、策略逻辑

最初拿到这么多因子的时候，又兴奋，又懵逼，然后随便选了一些来测试，结果均不理想。正在一筹莫展的时候。看到组长希勒推荐了两个帖子，一个是lava发布的关于因子分析的内容，一个是万家乐常卫全132131538发布的关于寻找最优组合的经验。在此感谢两位大佬，虽然现在还没有完全理解到所有因子的内涵，但以足够帮助我完成此次作业。经过多次测试，力图通过超跌反弹来进行选股，使用的都是这次小组提供的因子，逐渐找到这5个因子的组合：MACD三线，成交额稳定性_20日，协整偏离度_20日，量价协同强度_20日，龙头股特征_60日。暂且命名为MCXLL多维度超跌反弹策略。

这个策略的核心理念是：从多个维度识别被市场过度抛弃的股票。关于这5个因子的选股逻辑如下（参照DS写的，不知有无错误）:

因子	排序方式	选股逻辑	因子类型
MACD三线	True	选DIF最小的（空头动能最强）	反向动量
成交额稳定性_20日	True	选成交额最不稳定的	反向质量
协整偏离度_20日	True	选超卖最严重的	均值回归
量价协同强度_20日	True	选量价反向最强的	反向量价
龙头股特征_60日	True	选跑输大盘最多的	反向动量
二、参数
参数	数值
持仓周期	5D
选股数量	3
回测区间	2015-01-01 至今
初始资金	100 万
排除板块	创业板 / 科创板 / 北交所
再择时	动态模式切换
手续费 / 印花税	0.012% / 0.1%
三、策略代码
strategy = {
    'name': 'MCXLL多维度超跌反弹策略',
    'hold_period': '5D',
    'select_num': 3,
    "factor_list": [
        ('MACD三线', True, None, 1),
        ('成交额稳定性_20日', True, None, 1),
        ('协整偏离度_20日', True, None, 1),
        ('量价协同强度_20日', True, None, 1),
        ('龙头股特征_60日', True, None, 1),
    ],

    "filter_list": [
        ('近期涨跌幅', 5, 'pct:<0.4', True),
        ('月份', [1, 4 ], 'val:!=1'),
        ('市值', '', 'val:<=3e9', None),
    ]
}

days_listed = 250  # 上市至今交易天数

# excluded_boards = []  # 过滤板块，默认不过滤
excluded_boards = ["cyb", "kcb", "bj"]  # 同时过滤创业板和科创板和北交所

equity_timing = {"name": "动态模式切换", "params": ['sh000300',26, 28, 20, 60, 50, 3.0]}

四、资金曲线

未加择时的累计净值位1703.75。年化收益95.47%，最大回撤-30.88%。年化回撤比3.09。

感觉最大回撤有点高，于是又加上了上次参加再择时小组编写的择时信号“动态模式切换”，于是最终加了择时之后将最大回撤成功降低到了-20.87%。累计净值为603.01，年化收益78.01%，年化回撤比达到3.74。
