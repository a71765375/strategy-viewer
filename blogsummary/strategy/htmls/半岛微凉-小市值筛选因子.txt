3、单因子筛选
3.1 筛选因子候选

从因子库中筛选候选因子，排除以下三类：

市值相关因子（FILTER_EXCLUDE_AS_FILTER）：市值、总市值对数、流通市值对数等
过滤型因子（FILTER_FACTORS）：二值信号类因子（如三只乌鸦、红三兵等），不适合做排名也不适合做筛选

8、选股最终选择

下面来分析目前表现较好的因子组合：

趋势记忆衰减+换手率

收益回撤比较好的原因：

趋势记忆衰减筛选 — 选趋势记忆衰减最小的股票（pct:≤0.4），即价格趋势持续性最强的股票。从单因子排名看，它排在第3位（累积净值6437，年化65.47%），是动量类最强因子之一。
换手率筛选 — 低换手率（pct:≤0.4）意味着 筹码稳定、抛压小、主力控盘度高 。它的最大回撤仅-41.63%，收益回撤比1.49，在所有单因子中 风险控制最好 。
两者互补效应 — 趋势记忆衰减动量和低换手率是 两个不同类别 （动量类+成交量类），相关性低。动量因子负责选"涨得稳"的，低换手率因子负责选"没人卖"的，组合起来既选到了强势股、又过滤了高波动品种。
选5只+持5天 — 高度集中在小市值优质股，5天短频轮动，完美契合A股小盘股的快速轮动特性。

下面是单独回测结果：

9、择时优化

补充择时：经过优化，借鉴走天涯老板的择时因子，实现了在保证收益的情况下，降低了一定的回撤

择时因子为什么有效：

两种市况用两种策略，避免"一招死"

A股最大的特征就是 "牛短熊长、大部分时间震荡" 。单一策略必然失效：

纯趋势跟踪（双均线）：震荡市频繁金叉死叉 → 左右打脸
纯反转交易（布林带）：单边牛市早早卖飞、单边熊市抄底接飞刀
ADX就像一个 "市场模式检测器" ，把这两种策略用在各自适合的行情里。
用沪深300判大势，而非个股资金曲线

沪深300代表全市场主流资金方向。用大盘指数来判断市场模式， 信号更稳定 ，不会被个股的随机波动干扰。个股净值曲线可能因为选到妖股而暴涨暴跌，但大盘的趋势信号更可靠。

与小市值选股策略互补

小市值策略在下跌市中回撤极大（基准最大回撤 -40.55%）。动态择时会在 大盘趋势走坏或超买时减仓/空仓 ，有效规避系统性风险。

strategy = {
    'name': '趋势记忆衰减_换手率_5_基本面优化',  # 策略名
    'hold_period': '5D',  # 持仓周期，W 代表周，M 代表月，还支持日频：3D、5D、10D
    'select_num': 3,  # 选股数量，可以是整数，也可以是小数，比如 0.1 表示选取 10% 的股票
    "factor_list": [  # 选股因子列表
        ("市值", True, "", 1),  
    ],
    "filter_list": [  
        ("趋势记忆衰减", None, "pct:<=0.4",True),
        ("换手率", 5, "pct:<=0.4",True), 
        ("月份", [1,12], "val:!=1",True)   
    ] 
}

days_listed = 250  # 上市至今交易天数

# excluded_boards = []  # 过滤板块，默认不过滤
excluded_boards = ["bj", "cyb", "kcb"]  # 同时过滤创业板和科创板和北交所

equity_timing = {"name": "动态模式切换", "params": ['sh000300',20, 22, 20, 40, 20, 2.5]}
