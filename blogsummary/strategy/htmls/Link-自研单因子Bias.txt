一、策略基本配置

python版本：python3.11

需要安装的包：xbx-py11

回测区间：2009/01/01 – 2026/06/05

周期：3D

选股数量：3

换仓模式：'open'（开盘换仓）

排除板块：北交所/科创版/创业板

二、策略描述

基于尽可能简单的原则构建选股策略。构建思路：在小市值，低流动性的域内选择超跌的个股，利用小市值的反转效应。

三、策略代码

strategy = {
    'name': '策略',  # 策略名
    'hold_period': '3D',  # 持仓周期，W 代表周，M 代表月，还支持日频：3D、5D、10D
    'select_num': 3,  # 选股数量，可以是整数，也可以是小数，比如 0.1 表示选取 10% 的股票
    "factor_list": [  # 选股因子列表
        # ** 因子格式说明 **
        ('BbiBias', True, 5, 1),
    ],
    "filter_list": [
        ('市值', None, 'pct:<=0.3'),
        ('月份', [4, 1], 'val:!=1'),  # 不在4月份选股
        ('成交额STD', 20, 'pct:<=0.1'),
        ('成交额Mean', 5, 'pct:>=0.002'),

    ]  # 过滤因子列表
}

days_listed = 250  # 上市至今交易天数

excluded_boards = ["cyb", "kcb", "bj"]  # 同时过滤创业板和科创板和北交所

equity_timing = {"name": "移动平均线", "params": [18]}
