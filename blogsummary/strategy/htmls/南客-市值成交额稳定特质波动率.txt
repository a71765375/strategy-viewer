前言

本策略是"百因子小组-2期-2026"选股策略作业。策略基于邢不行选股框架，通过两阶段优化从4137组回测中筛选出最优配置：第一阶段对40组固定过滤配置进行100 trials选股因子贝叶斯搜索（3345组回测），第二阶段对24组最优配置进行33种择时参数寻优（792组回测）。回测区间为2009年1月至2026年6月，覆盖17年A股市场数据。

最终策略仅使用1个选股因子（总市值对数），配合3个前置过滤因子和1组复合择时信号，实现了Calmar比2.24的回测表现。策略的核心发现是：在充分过滤后的股票池中，单因子小市值选股已能提供充足的alpha，而真正决定策略上限的是择时——复合择时将最大回撤从-59.57%压缩至-21.97%，Calmar比从0.86提升至2.24。

策略思路

策略核心逻辑：通过多层量价过滤筛选出"成交量结构健康、无极端异动"的股票池，再用总市值对数选小盘，最后用复合择时信号控制系统性风险。

具体而言，策略分三层：

第一层是选股——总市值对数升序。A股小盘股长期存在流动性溢价和信息不对称溢价，总市值对数是该框架217个因子中与成交量类因子正交性最好的规模因子。在IC分析中，总市值对数的IC均值为-0.019、ICIR为-0.1、IC胜率55.59%，单看IC并不突出，但它在过滤后的股票池中表现极强——这说明过滤因子的作用是为小市值alpha"清理噪音"。

第二层是过滤——3个成交量结构因子。过滤的目标是排除那些"看起来是小盘股，但成交量结构异常"的陷阱票。三重过滤分别从季节性、波动率、极端收益三个维度刻画成交量健康度：

成交量季节性_月度（保留前30%）：过滤掉当前成交量相对历史同月均值偏离过大的股票，排除受季节性资金冲击的个股
成交量标准差_20日（保留前30%）：过滤掉成交量变异系数过高的股票，排除量能剧烈波动的个股
极端收益不对称_20日（保留前50%）：过滤掉20日内最大涨幅远超最大跌幅的股票，排除短期被爆炒的个股

第三层是择时——复合择时信号。这是策略回撤控制的关键。信号由两个独立维度取AND构成：策略级（净值>MA20）确保自身趋势向上，市场级（上涨广度>0.42）确保市场整体健康。只有两者同时满足才持仓，否则空仓。这一设计借鉴了可转债研究中"模块化正交叠加"的思路——用两个低相关的信号分别过滤不同维度的风险。

因子说明
选股因子说明

总市值对数来自框架内置因子库，参数为None（默认值）。选股方向为升序（True），即因子值越小越优先选中。

因子	IC均值	ICIR	IC胜率	计算逻辑	物理意义
总市值对数	-0.019	-0.10	55.59%	log(总市值 + 1)	公司规模因子，小市值具有流动性和信息不对称溢价

总市值对数的IC数据在217个因子中并不靠前，但它在多因子组合中表现极强。原因是：小市值因子的alpha来源是流动性溢价和信息不对称，这些溢价在成交量结构健康的股票池中更为纯净——过滤掉了受资金操纵或情绪驱动的个股后，小盘效应的信号噪声大幅降低。这一发现与2026年贝叶斯优化结果一致：在40组固定过滤配置的100 trials搜索中，总市值对数在Top 50结果中出现49次（98%），是绝对核心因子。

过滤因子说明

三个过滤因子均来自框架内置因子库，参数均使用默认值（None）。过滤方向全部为升序（True），即保留因子值较小的股票。

因子	IC均值	ICIR	IC胜率	过滤比例	计算逻辑	物理意义
成交量季节性_月度	-0.075	-0.68	77.30%	保留前30%	当日成交量 / 历史同月成交量均值	成交量相对历史同月的偏离度，越低越稳定
成交量标准差_20日	-0.045	-0.62	73.69%	保留前30%	std(20日成交量) / mean(20日成交量)	成交量变异系数，越低越平稳
极端收益不对称_20日	-0.033	-0.36	64.08%	保留前50%	max(20日涨幅) / max(20日跌幅)	极端正负收益比，越低越均衡

三个过滤因子的ICIR均为负值，意味着因子值越小（升序）的股票未来收益越好，与过滤方向一致。其中成交量季节性_月度的IC胜率高达77.30%，在全部217个因子中排名前列。

复合择时说明

复合择时信号由两个独立维度取AND构成，参数为[20, 0, 0.42]：

维度	信号	逻辑	作用
策略级	净值 > MA20	策略净值高于20日均线时持仓	过滤策略自身回撤趋势
市场级	上涨广度_20日 > 0.42	市场上涨股票占比超过42%时持仓	过滤市场系统性下跌

两个信号取AND：只有策略趋势向上且市场整体健康时才持仓，任一条件不满足即空仓。这一设计的核心价值在于正交性——策略级信号捕捉的是个股组合的动量，市场级信号捕捉的是市场整体情绪，两者相关度低，AND组合能有效过滤不同类型的风险。

回测设置

参数 值
回测区间 2009-01-01 ~ 2026-06-05
股票池 全A股（5858只），排除创业板和北交所
调仓周期 周频（每周最后一个交易日调仓）
持仓数量 5只
初始资金 1亿元
手续费 万1.2
印花税 千1（仅卖出）
资金曲线再择时 复合择时 MA20 + 上涨广度0.42

策略代码
```python
start_date = "2009-01-01"
end_date = "2026-06-05"

excluded_boards = ["cyb", "bj"]  # 排除创业板和北交所

strategy = {
    'name': '量价_复合择时_全局最优',
    'hold_period': 'W',
    'select_num': 5,
    "factor_list": [
        ('总市值对数', True, None, 1),  # 小市值alpha: 升序=选小盘
    ],
    "filter_list": [
        ('成交量季节性_月度', None, 'pct:<0.3', True),   # 保留前30%
        ('成交量标准差_20日', None, 'pct:<0.3', True),   # 保留前30%
        ('极端收益不对称_20日', None, 'pct:<0.5', True),  # 保留前50%
    ]
}

days_listed = 250
initial_cash = 1_0000_0000
c_rate = 1.2 / 10000
t_rate = 1 / 1000
n_jobs = os.cpu_count() - 1

equity_timing = {"name": "复合择时", "params": [20, 0, 0.42]}
# 复合择时参数: [MA周期=20, 信号类型=0(上涨广度), 阈值=0.42]

以下为启用复合择时后的回测结果（再择时资金曲线）：

在2009年至2025年的年度统计中，所有年份均录得正收益。最差年份为2020年的0.39%和2025年的7.33%。2009年因因子滚动窗口原因，实际起始日期为2009年2月6日。

策略优点

择时效果显著：复合择时将最大回撤从-59.57%降至-21.97%，Calmar比从0.86提升至2.24。核心机制是在市场系统性下跌时主动空仓——当上涨广度跌破42%或策略净值跌破MA20时，策略自动离场，避免了2015年股灾和2018年熊市的主要跌幅。
年度胜率100%：17个完整年度（2009-2025）全部正收益，无一亏损。这得益于择时信号在熊市初期的快速离场——2018年仍获7.86%正收益，而同期未择时为10.92%（虽正但回撤巨大）。
因子极简：仅1个选股因子（总市值对数）+3个过滤因子，结构清晰。总市值对数在Top 50贝叶斯搜索结果中出现率98%，是经过4137组回测验证的核心因子。
过滤与选股正交：3个过滤因子（成交量季节性、成交量标准差、极端收益不对称）从不同维度刻画成交量健康度，与小市值选股因子逻辑正交——过滤负责"排雷"，选股负责"抓alpha"，职责分明。
无未来函数：所有因子计算（rolling、expanding、groupby）均为纯向后看，选股流程按日期分组横截面排名，模拟器采用"收盘卖、次日开盘买"的时序，复合择时信号中的市场情绪数据用日期对齐，不存在未来数据泄漏。

策略不足

日线胜率偏低：再择时后日胜率仅37.50%，低于未择时的57.97%。原因是复合择时在震荡市中频繁开关仓，空仓期间产生大量零收益日，拉低了胜率。但盈亏收益比从0.94提升至2.53，"少赚多赚"的特征明显——胜率低但单次盈利远大于单次亏损。
最大连续亏损周期数较高：60个交易日（约3个月），出现在震荡市中择时信号反复触发的阶段。虽然每次亏损幅度很小（单周期最大亏损-9.79%），但连续小亏的体验不佳。
2015年收益极端：518.29%的年度收益包含了股灾前后的极端波动，这一单年收益对未来表现不具备参考价值。若剔除2015年，其余16年年化收益约38%。
持仓集中度高：仅持有5只股票，单票集中度20%。随资金规模增大，小盘股的冲击成本将显著上升，实际容量受限。
择时参数可能过拟合：复合择时的三个参数（MA20、上涨广度0.42、AND逻辑）是在24组配置×33种择时的792组回测中筛选出的最优，存在一定过拟合风险。参数微调（如MA15或广度0.45）的表现需要进一步验证。
未考虑交易容量：策略持仓集中在小市值股票，随资金规模增大，冲击成本将显著上升。本文中的回测未考虑流动性约束和滑点。
