一、策略核心思路

本策略采用「小市值 + 量价背离双因子选股 + 资金曲线布林带择时」，核心目标是尽量减轻小市值策略「高收益、高回撤」的固有痛点。

选股方面，以 A 股长期验证有效的「小市值」因子为主力（权重 6），叠加「量价相关系数」因子（权重 4）作为增强——该因子计算每只股票过去 11 个交易日收盘价与成交量的滚动相关系数。当相关系数为负，说明量与价反向运动（放量不涨 / 缩量拉升），往往暗藏主力暗中操作痕迹。对于盘子小、容易留下资金痕迹的小市值股票，这一信号尤为有效。二者加权复合排序，挑选市值小且量价背离最为明显的标的。

择时方面，用布林带对策略自身的资金曲线净值做二次择时：跌破下轨空仓、站上中轨满仓，在市场整体走弱时自动降低仓位，削减回撤。

2. 选股因子

策略使用两个因子，按权重加权合成复合选股因子，最终取排名前 10 的股票。

因子一：市值（权重 6）

排序方式：升序，从小到大优先
逻辑：A 股市场长期验证，小市值股票具有显著超额收益。因子无需额外参数，直接使用个股总市值。

因子二：量价相关系数（权重 4）

排序方式：升序，从小到大优先（值越负越靠前）
参数：滚动窗口 11 个交易日
逻辑：计算每只股票过去 11 个交易日内「收盘价」与「成交量」的 Pearson 滚动相关系数，取值区间 [-1, +1]。相关系数为负，说明量与价呈反向关系：
价格下跌但成交量放大 → 恐慌抛售后的潜在反转
价格上涨但成交量萎缩 → 主力控盘后的锁仓信号
因子值越负（量价背离越严重），越可能是变盘前夕，在小市值场景中尤为敏感。
因子内部使用时序百分位排名（pct rank）归一化，天然完成去量纲 + 去极值 + 跨股票可比。
3. 布林带择时规则
配置项	参数
择时对象	策略自身的资金曲线净值
布林带周期	9
标准差倍数	1.5

信号逻辑：

信号	触发条件	操作
空仓信号	当日净值跌破布林带下轨，且昨日净值未跌破下轨	卖出全部持仓，仓位归零
做多信号	当日净值站上布林带中轨，且昨日未站上	买入，恢复满仓

仓位管理：

信号值 1 = 满仓做多，0 = 空仓
信号向前填充（forward fill），保持持仓状态不变，直至下一信号触发
缺失值默认满仓（回测初期布林带数据不足时不触发空仓）

2.量价相关系数因子
"""
量价相关系数 — 收盘价与成交量的滚动相关系数

核心逻辑:
    计算过去 N 日收盘价与成交量的滚动相关系数（[-1, +1]）。
    相关系数为负 = 量价背离 → 价格与成交量走势相反 → 主力暗中操作痕迹。
    「放量不涨」或「缩量拉升」都是负相关的典型表现。

适配小市值:
    小票盘子小，主力建仓/出货容易在量价关系上留下痕迹；
    滚动相关系数对这类隐性资金动作敏感，负相关越强信号越明确。

配置方式: 升序排序（True），值越小（越负为量价背离）越优先
    因子列表: ('量价相关系数', True, 10, 1)
"""

import pandas as pd

fin_cols = []


def add_factor(df: pd.DataFrame, param=None, fin_data=None, **kwargs) -> (pd.DataFrame, dict):
    """
    量价相关系数因子

    param: 滚动窗口天数，默认 5
    """
    col_name = kwargs['col_name']
    window = int(param) if param is not None else 5

    close_ = df['收盘价_复权']
    volume = df['成交量']

    # 滚动协方差 / (std_close * std_vol) = 滚动相关系数，[-1, 1]，天然跨股票可比
    cov = close_.rolling(window, min_periods=window).cov(volume)
    std_c = close_.rolling(window, min_periods=window).std()
    std_v = volume.rolling(window, min_periods=window).std()
    result = cov / (std_c * std_v + 1e-8)

    # 升序排序：负值（量价背离）排前面
    factor_df = pd.DataFrame({col_name: result}, index=df.index)
    return factor_df, {col_name: 'last'}

3.布林带择时
import pandas as pd

def equity_signal(equity_df: pd.DataFrame, *args) -> pd.Series:
    """
    根据资金曲线，使用布林带构建择时信号

    :param equity_df: 包含 '净值' 列的资金曲线 DataFrame
    :param args: 策略参数 [布林带周期, 标准差倍数]
    :return: 择时信号 Series（1=做多，0=空仓）
    """
    # ====================== 参数解析 ======================
    n = int(args[0]) if len(args) >= 1 else 9
    std_multiplier = float(args[1]) if len(args) >= 2 else 1.5

    # 简化净值引用
    nav = equity_df["净值"]

    # ====================== 布林带计算 ======================
    # 滚动窗口计算：min_periods=1
    rolling = nav.rolling(window=n, min_periods=1)
    ma = rolling.mean()
    std = rolling.std()

    upper_band = ma + std_multiplier * std
    lower_band = ma - std_multiplier * std

    # ====================== 信号条件 ======================
    # 卖出条件：今日跌破下轨 + 昨日未跌破
    sell_condition = (nav < lower_band) & (nav.shift(1) >= lower_band.shift(1))

    # 买入条件：今日站上中轨 + 昨日未站上
    buy_condition = (nav > ma) & (nav.shift(1) <= ma.shift(1))

    # ====================== 信号生成 ======================
    signals = pd.Series(1.0, index=equity_df.index)
    signals[sell_condition] = 0.0
    signals[buy_condition] = 1.0

    # 前向填充保持持仓状态 + 缺失值默认做多
    signals = signals.ffill().fillna(1.0)

    return signals
