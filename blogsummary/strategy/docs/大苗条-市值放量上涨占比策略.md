二、策略讲解
再择时的三个参数讲解：
20：退出均线：净值跌破20日均线 → 空仓
3：入场均线：净值站上3日均线 → 可能入场
7：中证2000指数站上7日均线 → 确认恢复
择时逻辑（逐日判断）
持仓状态 → 空仓：当策略净值跌破20日均线时，全部卖出，进入空仓。
空仓状态 → 入场，需满足以下任一条件：
标准恢复：净值重新站上20日均线
提前入场：中证2000指数站上7日均线 且 净值站上3日均线
为什么有效？
小市值策略和中证2000指数高度相关。当市场从下跌转为上涨时，指数往往比个股净值更快恢复。利用指数的短MA（7日）作为先行指标，可以在净值还没恢复到20日均线时就提前入场，少踏空、多吃一段反弹。
这就是为什么entry_n=3（极短的3日均线）和idx_ma_n=7配合如此有效——3日均线非常敏感，净值稍有反弹就会触发；但单独用净值3日
均线入场会有太多假信号，所以加上"指数也要确认恢复"这个条件来过滤。
