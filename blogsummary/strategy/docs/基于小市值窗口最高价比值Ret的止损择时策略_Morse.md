## 策略概述
- 在小市值策略基础上增加止损择时，偏好从高点回落到一定幅度将要反转的股票介入
- 短期3D持股，持股时间变长收益会受影响
- 灵感来源：宁月大佬 https://bbs.quantclass.cn/thread/60888

## 一、策略思路

一直关注小市值策略的各种拓展，在学习了宁月大佬的帖子后，对于择时有了更进一步的了解，因此在此前用过的小市值、窗口最高价比值、Ret这三个排序因子的基础上，增加了止损择时的择时因子，以便能提升收益/回撤比。

## 二、策略描述

总的说来是在小市值股票回撤到一定幅度将要反转时介入，短期3D持股。此前测试过，如果持股时间变长，收益会受影响。

## 四、策略代码

### 止损择时函数（equity_signal）

```python
def equity_signal(equity_df: pd.DataFrame, *args) -> pd.Series:
    """
    基于止损的择时信号（只有满仓或空仓两种状态）
    当资金曲线在近期跌幅超过阈值时，空仓
    其他情况，满仓

    :param equity_df: 资金曲线的DF
    :param args: 其他参数
        args[0]: 止损观察周期
        args[1]: 止损阈值
    :return: 返回包含 leverage 的数据
    """
    stop_loss_period = int(args[0])
    stop_loss_threshold = float(args[1])

    short_ret = equity_df["净值"].pct_change(stop_loss_period)

    signals = pd.Series(1.0, index=equity_df.index)
    signals[short_ret < stop_loss_threshold] = 0.0

    print("止损信号：", signals.describe())
    return signals
```

## 六、总结

在收益率基本没变的情况下（73.80%→72.03%），通过止损择时降低了回撤（28.76%→25.82%），把收益/回撤比从2.57提高到2.79。作者明确表示不过度优化避免过拟合，态度务实。
