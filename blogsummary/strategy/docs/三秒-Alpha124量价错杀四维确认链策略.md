3.1 Alpha124：VWAP量价错杀是核心
Alpha124 = (收盘价 - VWAP) / 自稳分母。VWAP是成交量加权均价——"真金白银成交的平均成本"。
收盘低于VWAP = 收在市场平均成本线下 → 短期回补动力。分母自动根据近期高点位置缩放信号强度。
——在量价类因子中极为少见，接近质量因子水平。
3.2 四维确认链：四个时间维度同时确认"跌够"
四个维度同时指向"超跌"时，Alpha124做最终仲裁。不是简单的因子堆叠——每个维度覆盖不同时间尺度，互不冗余。
五个因子中四个在量同一方向（超跌），Alpha124做最终排序。2只 = 只取最极端信号。加到5只会拉进"不够极端"的票，Calmar从2.59线性衰减到2.07。
轻仓择时 [3,9,20,2.0] 比常规更灵敏——短均线3/9日，适配2只极端集中的快速回撤。
3.4 窗口最低价比值：切掉"跌得不够透"的垃圾
窗口最低价比值 pct&gt;=0.38 = 股价不能贴近60日最低点。这条过滤是生命线——去掉后Calmar从2.59崩到1.84。
ICIR = 组合贡献。bias/hh单看IC不高，但它们的价值不在排序而在"确认"——四个维度同时指向超跌时才出手。
Alpha124 ICIR全场最强，且信号自带VWAP路径信息和分母自稳，对参数窗口不敏感——这是选择它而非Ret作为核心信号的原因。
4.3 分箱揭示的倒U型：为什么权重结构这么设
曲线是倒U型。最深折价（第1组，净值2.10）不如适度折价（第4~5组，净值4.8~5.1）。极端VWAP折价里混着"真在崩"的票——Alpha124单用会踩坑。
所以Alpha124只有0.3权重。**它是方向盘——告诉你往折价方向找。但不是油门。bias/hh合计权重2.0——它们负责把第1组"VWAP折价深但还在加速跌"的票过滤掉，把选股推到第3~6组的甜点区。
第8组以后直接归零。收盘高于VWAP的票长期无alpha。A股只做反转不做动量——这是选择Alpha124升序（折价优先）的根本原因。
5.1 核心稳健区：hh窗口 × Alpha124窗口
hh120+Alpha124 真稳健区确认。5个窗口值全在2.26~2.59，极差仅0.33。两端边界（a124=5和a124=40）分别是2.26和2.40——两端都不崩。
Alpha124天然窗口不敏感：VWAP自带路径信息（不是只看两个端点），分母根据近期高点位置自动缩放信号强度。
线性衰减而非断崖。每多持1只≈掉0.13 Calmar。n=5仍有2.07——底线超过大多数策略的峰值。
完整稳健区确认。双向测试0.1~1.0，0.1和0.3并列最高（2.60/2.59），0.2有个小坑（2.32）。0.5开始明显衰减。
Alpha124不需要高权重——0.1~0.4即可，过高（≥0.5）bias/hh被压缩后确认链失效。
窗口最低价过滤不可动：去掉崩到1.84，放宽到pct≥0.2崩到2.01。

最大回撤-38.37%，发生在2017-01-10至2018-02-06。2017年全年小票风格失效，策略连续亏损。
2只极端集中——一只跌停即腰斩一半。虽然≤30亿池天然避跌停（千面数据验证），但极端行情下仍有尾部风险。
2只×微盘 = 资金容量极小。小资金回测效果好，实盘规模增大后滑点显著。
策略高度依赖小市值风格。2017年小票全年失效时策略-4%（周金涛基准数据），实盘需有风格失效预警。
