## 策略概述

从多个维度识别被市场过度抛弃的股票。受 lava 和万家乐常卫全的因子分析方法启发，通过组合5个反向因子构建超跌反弹策略。

**择时加成**：加入"动态模式切换"择时信号后，最大回撤从-30.88%降至-20.87%。

> ⚠️ 有评论指出择时代码存在 `ffill()` bug（趋势信号一旦为1就永远为1），高收益可能部分依赖此 bug。

## 因子清单

### 选股因子（5个，全部升序）

| 因子 | 选股逻辑 | 因子类型 |
|------|---------|---------|
| MACD三线 | DIF最小（空头动能最强） | 反向动量 |
| 成交额稳定性_20日 | 成交额最不稳定 | 反向质量 |
| 协整偏离度_20日 | 超卖最严重 | 均值回归 |
| 量价协同强度_20日 | 量价反向最强 | 反向量价 |
| 龙头股特征_60日 | 跑输大盘最多 | 反向动量 |

### 过滤与配置

```python
"filter_list": [
    ('近期涨跌幅', 5, 'pct:<0.4', True),
    ('月份', [1, 4 ], 'val:!=1'),
    ('市值', '', 'val:<=3e9', None),
]

days_listed = 250
excluded_boards = ["cyb", "kcb", "bj"]  # 排除创业板/科创板/北交所

equity_timing = {"name": "动态模式切换", "params": ['sh000300', 26, 28, 20, 60, 50, 3.0]}
```

## 总结

走天涯的策略采用全新的因子组合（非百因子小组常用集），从MACD、成交额稳定性、协整偏离度、量价协同、龙头股特征5个维度综合识别超跌股票。排除创业板/科创板/北交所后，在2015-2026实现78%年化、20.87%回撤。已注意的是择时代码存在 `ffill` bug（评论指出），需核实。
