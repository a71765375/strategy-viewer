# 基于5因子复合评分+中证500趋势择时的量化选股策略

## 策略概述
- 策略名称：5因子复合量价择时策略
- 作者：相空
- 来源：量化小论坛

## 附件信息
- 无

## 一、策略思路

**核心思路**：在 A 股小市值风格收益来源中，叠加多维度量价因子筛选，配合宏观趋势择时，精准捕捉"被市场冷落的低换手小盘股"在趋势上行期的超额收益。

两个设计方向：
- **选股**：用量价行为因子（缩量、缩波、低换手、成交额STD）刻画"被机构遗忘的冷门小盘"，具有反转潜力
- **择时**：用中证500趋势均线作为宏观牛熊切换过滤器，趋势向下时严格空仓

## 二、策略描述

### 2.1 选股因子（5个，均取值越小越好，升序选股）

| 因子 | 参数 | 经济含义 | ICIR |
|------|------|---------|------|
| 成交额缩量因子 | (10, 60) | 短期/长期成交额均值比，越小代表近期越缩量（机构撤退） | 0.310 |
| 成交额缩波因子 | (10, 60) | 短期/长期成交额波动比，越小代表成交越平静（热度消退） | 0.390 |
| 市值 | - | 总市值越小代表小盘股，享受小市值溢价 | 0.160 |
| 换手率 | 1日 | 成交额/流通市值，越低代表换手越清淡（机构不关注） | 0.448 |
| 成交额STD | 10日 | 成交额10日滚动标准差，越小代表成交量波动越小（极端冷门） | 0.530 |

**设计逻辑**："缩量 + 缩波 + 低换手 + 低STD"组合共同描述"冷门股"特征——被所有人遗忘、成交量清淡且稳定，反弹时弹性最大。

### 2.2 择时信号

- 中证500（sh000905）MA25 单均线
- 规则：收盘价 > MA25 → 满仓；收盘价 < MA25 → 空仓

### 2.3 策略参数

- 持仓周期：3D（三日轮动）
- 选股数量：5支
- 过滤条件：市值前80%（pct≤0.8）+ 换手率前80%（pct≤0.8）
- 回测时间：2009-01-01 至 2026-03-23

```python
def equity_signal(equity_df: pd.DataFrame, *args) -> pd.Series:
    n = int(args[0]) if len(args) > 0 else 20
    index_df = pd.read_csv(index_file, parse_dates=['candle_end_time'])
    merged_df = pd.merge(equity_df[['交易日期']], index_df[['交易日期', 'close']], on='交易日期', how='left')
    merged_df['close'] = merged_df['close'].ffill()
    ma = merged_df['close'].rolling(n, min_periods=1).mean()
    signals = pd.Series(0.0, index=merged_df.index)
    signals[merged_df['close'] > ma] = 1.0
    return signals
```

### 成交额缩量因子.py

```python
def add_factor(df, param, **kwargs):
    short = param[0]   # 10日
    long  = param[1]   # 60日
    short_mean = df['成交额'].rolling(short).mean()
    long_mean  = df['成交额'].rolling(long).mean()
    factor_col = short_mean / long_mean
    return pd.DataFrame({col_name: factor_col}, index=df.index), {col_name: 'last'}
```

### 成交额STD.py

```python
def add_factor(df, param=None, **kwargs):
    n = int(param)   # 10日
    df[col_name] = df['成交额'].rolling(n).std()
    return df[[col_name]], {col_name: 'last'}
```

## 四、总结

本策略通过"5个冷门股量价因子 + 中证500 MA25择时"的组合，在17年回测中实现了年化36.18%、最大回撤-23.66%、Calmar=1.53的表现。

关键发现：
- **成交额STD** ICIR=0.530，是最强因子
- **换手率** ICIR=0.448，次优
- 市值因子 ICIR 最低（0.16），但提供了显著的长期净值贡献
- Ret（近期反转因子）对本策略有害，加入后 Calmar 从 1.46 暴跌至 0.81
