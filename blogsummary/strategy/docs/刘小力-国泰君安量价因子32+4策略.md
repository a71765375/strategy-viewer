## 策略思路

一、策略思路
延续之前的国泰短期量价因子，内容太多了，电脑算力不够，慢慢的来用
发现32号因子似乎在和其他因子组合中都有不错的结果，所以以它和市值，外加一个因子进行分析
时间选择2018年-现在，因为2015，2017年是极端情况，距离现在太远不具备参考意义，如果只放近3年，又势必会被14下半年，15年的暴涨导致结果太好
二、策略描述
整体还是在小市值中识别反转、确认情绪，并且以与小市值高度相关的指数中证2000来确认持仓信号
1）国泰alpha32——量价相关性
用过去n天的"价格排名与成交量排名"的相关性强度，识别持续追高的风险。我曾经使用过多次不同方式的量价相关性，发现在小市值这种反转形态市场，相关性低（接近0）的股票，在后期会有更好的涨幅，说不清楚为什么，ai告诉我相关性弱表示股票理性上涨（？？为什么），但总归，结果是高度一致的，这个因子作为短期风险警报器，不预测涨跌，只识别"追高程度"。
2）国泰alpha4——一个买卖开关
这是一个二元信号因子（只返回 1 或 -1），核心思想：分层决策 + 价量平衡。
三层判断逻辑：
第一层（绝对优先）：价格超买？
如果 2日均价 &gt; (8日均价 + 8日标准差) → 返回 -1（卖出）
原因：超买是强信号，不管量，先规避
第二层：价格超卖？
如果 2日均价 &lt; (8日均价 - 8日标准差) → 返回 1（买入）
原因：超卖是强信号，不管量，先抄底
第三层（正常区间）：看成交量
如果 今日成交量 ≥ 20日平均成交量 → 返回 1（买入，有资金在布局）
否则 → 返回 -1（卖出，无人问津）
3）指数择时LLT三仓位——我的斜率择时信号
用低延迟趋势线 LLT 跟踪中证 2000 指数，通过斜率判断趋势强弱，实现 0/0.5/1 三档仓位管理，并且在空仓和全仓之间，我增加了一个半仓，实际我实盘中也是如此操作
明确上升趋势 → 满仓 1.0
明确下降趋势 → 空仓 0.0
趋势模糊/震荡 → 半仓 0.5
小市值因子不再赘述
