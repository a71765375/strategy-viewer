# 北海鳄神-总市值成交额STD回归动量选股策略

**作者**: 北海鳄神

## 策略思路

本策略做"小市值超跌反弹"的策略——回归动量，买的是离60日高点最远、跌得最惨的小盘股。利用A股价值回归的原则进行抄底。两个因子（小市值+超跌偏离回归），每3天换5只，2009年至今净值12,289倍，年化135.34%。
二、交易逻辑
选股因子（等权复合排名）
因子1：总市值 × 成交额10日标准差（升序）
取总市值与成交额10日标准差的乘积，值越小排名越靠前。
物理直觉：小市值且成交额波动小的股票，往往是被市场忽视的"冷门股"。A股题材炒作的发动机永远是小盘股——信息不对称程度高、机构覆盖少、筹码结构轻，一旦有催化剂，弹性远大于大市值股票。成交额标准差低，说明没有资金提前埋伏，爆发力更强。
因子2：动量因子（降序 → 实际升序）
原设计为20日动量（降序，追涨），但实证发现升序效果碾压降序。即选出最近20日跌得最多的小盘股。
物理直觉：这个因子原设计是捕捉突破追涨，但实证发现小盘股叠加超跌（跌得越惨越好），产生极强的均值回归弹性——跌透了的小盘股一旦反弹，空间巨大。这本质是"小市值 + 超跌反弹"，不是追涨突破。
过滤规则（三层预筛）
排除收盘价≈最低价的股票
去掉弱势股（无下影线=无支撑）
20日均成交额 ≥ 500万
保证流动性，排除僵尸股
总市值 ≥ 9亿
排除壳资源/退市边缘
排除：科创板(sh688)、北交所(bj)
每 3个交易日 调仓一次，每次持有 5只 股票
