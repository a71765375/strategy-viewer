## 一、策略思路

从单一 RSV 择时出发，逐步探索多指标投票制组合择时方案。核心思想是：**单一指标容易产生误判，采用多指标投票制可以过滤噪音、提高鲁棒性**。

## 二、策略描述

### 2.1 RSV 择时（单一指标基准）

**RSV 原理**：
```
RSV = (Close - Low_N) / (High_N - Low_N) × 100
```

对资金曲线的净值序列计算 RSV，当 RSV 突破上下轨时切换持仓状态：
- RSV < 下轨 → 超卖区，买入（信号=1）
- RSV > 上轨 → 过热区，清仓（信号=0）
- 中间区域 → 维持前一状态

**实验结论**：单一 RSV 对资金曲线择时效果有限，回撤幅度仍在 38% 左右，收益回撤比 < 1。

### 2.2 多指标投票制组合择时

**设计思路**：每个指标独立产生看多/看空信号（1 或 0），当看多票数 ≥ 阈值时持仓，否则空仓。

**策略参数**：`(n1, n2, threshold)` — 均线周期、RSV周期、投票阈值

## 三、五个投票指标详解

### 指标1：均线趋势

**看多条件**：净值 > MA(n1)

最基础的趋势判断方法。移动平均线本质上是对净值曲线做平滑，过滤掉短期噪音后得到中期趋势方向。

- 参数 n1 越小，均线越灵敏，跟踪越紧，但假信号也越多
- 参数 n1 越大，均线越平滑，信号越稳定，但反应越滞后
- **当前最优 n1=10**，属于偏短的均线，适合捕捉资金曲线的快速变化

### 指标2：均线斜率

**看多条件**：MA(n1) 的近 slope_win 日差分 > 0（其中 slope_win = max(n1/4, 3)）

均线趋势只看"净值和均线的相对位置"，但有一种情况会误判：净值虽然在均线上方，但均线本身已经开始拐头向下——这往往是趋势即将反转的前兆。

**和指标1配合使用**：
- 指标1看"净值在均线哪一侧"（位置）
- 指标2看"均线自身的方向"（方向）
- 两者都看多时，趋势确认度更高

### 指标3：RSV 状态信号

**看多条件**：RSV(n2) < 20 时买入，RSV(n2) > 80 时清仓，中间区域维持前一状态

RSV 衡量的是当前净值在近期波动区间中的相对位置（0~100）。它和均线趋势视角不同：
- 均线趋势看"趋势方向"
- RSV 看"位置是否极端"

**关键设计**：采用**状态保持**机制（而非每日重新判断），只在突破上下轨时切换状态，中间区域保持不变。这避免了 RSV 在中间区域反复震荡时频繁切换信号。

### 指标4：回撤保护

**看多条件**：当前回撤幅度 < 15%

这是一个风控性质的指标。前三个指标都在试图判断"趋势方向"，但如果策略已经出现较大回撤（>15%），说明可能遭遇了系统性风险或策略失效，此时无论其他指标如何判断，都应该投一票看空以降低仓位。

**和其他指标的区别**：
- 指标1-3 是"进攻型"，判断什么时候该买
- 指标4 是"防守型"，判断什么时候必须撤
- 15% 的阈值是硬编码的，不受参数影响

### 指标5：动量确认

**看多条件**：近 mom_win 日收益率 > 0（其中 mom_win = max(n1/2, 5)）

动量效应是金融市场中最稳健的异象之一：近期涨的资产倾向于继续涨，近期跌的倾向于继续跌。

**和均线趋势的区别**：
- 均线趋势比较的是"当前值 vs 过去均值"，是位置关系
- 动量比较的是"当前值 vs 过去某一天"，是变化率
- 动量窗口（n1/2）比均线周期短，反应更快

## 四、投票汇总机制

五个指标各投一票（1=看多，0=看空），汇总后与阈值比较：

```python
# 当前最优参数
equity_timing = {"name": "组合择时", "params": [10, 40, 3]}
```

- **threshold=3**：即 5 票中至少 3 票看多才持仓
- 允许最多 2 个指标发出看空信号，具有一定的容错能力

**投票制的优势**：
1. **鲁棒性**：单个指标失灵不会导致整体误判
2. **多维度**：从趋势、超买超卖、风控、动量四个维度交叉验证
3. **可解释性**：每个信号的来源清晰，便于诊断和调优

## 五、回测结果

| 指标 | 无择时 | 组合择时 [10, 40, 3] |
|------|--------|---------------------|
| 年化收益 | 31.16% | 31.86% |
| 最大回撤 | -44.41% | -23.01% |
| 收益回撤比 | 0.70 | 1.38 |

**效果**：年化收益基本持平，最大回撤从 44% 降至 23%，收益回撤比从 0.70 提升至 1.38，**接近翻倍**。

## 六、结论

1. **单一 RSV 择时效果有限**：对资金曲线的择时不如对价格序列的择时有效，容易产生滞后和误判
2. **投票制组合择时显著优于单一指标**：多指标互相验证可以过滤掉大部分噪音信号
3. **最优参数 [10, 40, 3]**：短均线（10日）+ 中等RSV周期（40日）+ 5票中3票通过
4. **核心价值在于回撤控制**：年化收益几乎无损（31.16% → 31.86%），但回撤减半（44% → 23%）
