# 叶晓思-总市值量价小市值复合择时

**作者**: 叶晓思

## 策略思路

最终策略仅使用1个选股因子（总市值对数），配合3个前置过滤因子和1组复合择时信号，实现了Calmar比2.24的回测表现。策略的核心发现是：在充分过滤后的股票池中，单因子小市值选股已能提供充足的alpha，而真正决定策略上限的是择时——复合择时将最大回撤从-59.57%压缩至-21.97%，Calmar比从0.86提升至2.24。
策略思路
策略核心逻辑：通过多层量价过滤筛选出"成交量结构健康、无极端异动"的股票池，再用总市值对数选小盘，最后用复合择时信号控制系统性风险。
具体而言，策略分三层：
第一层是选股——总市值对数升序。A股小盘股长期存在流动性溢价和信息不对称溢价，总市值对数是该框架217个因子中与成交量类因子正交性最好的规模因子。在IC分析中，总市值对数的IC均值为-0.019、ICIR为-0.1、IC胜率55.59%，单看IC并不突出，但它在过滤后的股票池中表现极强——这说明过滤因子的作用是为小市值alpha"清理噪音"。
第二层是过滤——3个成交量结构因子。过滤的目标是排除那些"看起来是小盘股，但成交量结构异常"的陷阱票。三重过滤分别从季节性、波动率、极端收益三个维度刻画成交量健康度：
成交量季节性_月度（保留前30%）：过滤掉当前成交量相对历史同月均值偏离过大的股票，排除受季节性资金冲击的个股
成交量标准差_20日（保留前30%）：过滤掉成交量变异系数过高的股票，排除量能剧烈波动的个股
极端收益不对称_20日（保留前50%）：过滤掉20日内最大涨幅远超最大跌幅的股票，排除短期被爆炒的个股
第三层是择时——复合择时信号。这是策略回撤控制的关键。信号由两个独立维度取AND构成：策略级（净值&gt;MA20）确保自身趋势向上，市场级（上涨广度&gt;0.42）确保市场整体健康。只有两者同时满足才持仓，否则空仓。这一设计借鉴了可转债研究中"模块化正交叠加"的思路——用两个低相关的信号分别过滤不同维度的风险。
