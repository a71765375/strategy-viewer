# 南客-市值成交额稳定特质波动率

**作者**: 南客

## 策略思路

因此，策略通过以下三层逻辑进行选股：
总市值对数：保留小， 保持上涨概率，原本想用反转因子 但是效果很差
成交额稳定性：尽量求取稳定
索提诺比率： 稳定求上进
二、策略参数

## 选股因子

| 因子 | 排序 | 参数 | 权重 |
|------|------|------|------|
| 总市值对数 | 升序 | None | 1 |
| 成交额稳定性_20日 | 升序 | None | 1 |
| 特质波动率_60日 | 升序 | None | 1 |
| 索提诺比率_60日 | 升序 | None | 1 |

## 可取之处

小市值为核心因子，享受A股小盘溢价。 成交额类因子捕捉市场关注度变化，非热股选股思路。
