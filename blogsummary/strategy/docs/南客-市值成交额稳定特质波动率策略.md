# 南客-市值成交额稳定特质波动率

**作者**: 南客

## 策略思路

一、策略思路
本策略核心思路是试图走市值+稳定性来构建一个策略， 原本表现很好，但是在今年行情下，出现大幅回撤。
因此，策略通过以下三层逻辑进行选股：
总市值对数：保留小， 保持上涨概率，原本想用反转因子 但是效果很差
成交额稳定性：尽量求取稳定
索提诺比率： 稳定求上进
