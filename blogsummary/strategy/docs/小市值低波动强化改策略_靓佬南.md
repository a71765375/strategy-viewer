## 一、策略描述

- **持仓周期**：5D
- **回测时间**：2009-01-01 至今
- **选股数量**：5
- **策略名**：小市值低波动强化改

## 二、策略代码

```python
strategy = {
    'name': '小市值低波动强化改',
    'hold_period': '5D',
    'select_num': 5,
    'factor_name': '小市值低波分数',
    "factor_list": [
        ('Alpha159', False, None, 0.3),  # Alpha159：分位段趋势，越大越优
    ],
    "filter_list": [
        ('市值', None, 'pct:<=0.05', True),
        ('成交额STD', 15, 'pct:<=0.3', True),
        ('近期涨跌幅', 5, 'pct:<=0.3', True),
        ('月份', [1, 4], 'val:!=1'),
    ]
}

days_listed = 250
excluded_boards = []
equity_timing = {"name": "上证成本均线", "params": [5]}
```

## 三、因子说明

**1. Alpha159（选股因子）**
- **原理**：分位段趋势因子，越大越优
- **逻辑**：衡量价格在分段区间中的趋势强度
- **权重**：0.3

**2. 市值（过滤因子）**
- **条件**：市值排名前5%（即最小的5%）
- **逻辑**：聚焦微盘股，享受小市值溢价

**3. 成交额STD（过滤因子）**
- **参数**：15日
- **条件**：成交额标准差排名前30%（即波动最小的30%）
- **逻辑**：选成交额波动小的，排除交易过热的股票

**4. 近期涨跌幅（过滤因子）**
- **参数**：5日
- **条件**：近期涨跌幅排名前30%（即涨幅最小的30%）
- **逻辑**：选近期滞涨的，不追高

**5. 月份（过滤因子）**
- **参数**：[1, 4]
- **条件**：排除1月和4月
- **逻辑**：1月和4月可能是年报/一季报披露期，小盘股容易踩雷

## 四、择时方法

**上证5日成本均线择时**
- 根据上证指数的5日成本均线进行资金曲线再择时
- 总结原文："改用上证5日成本均线择时"

## 八、评价

- **优点**：Alpha159因子（分位段趋势）是较新的因子，月份过滤有创意（排除1月4月），5D持仓+5只股票降低了换手
- **问题**：回撤比仅0.86（回撤53.66%太大），2015年6-7月最大回撤，手续费927万偏高，择时效果不理想（上证成本均线未能有效降低回撤）
- **对比**：同为小市值策略，策略5（止损择时）回撤比2.79、策略6（MA择时）回撤比1.85，远优于本策略
