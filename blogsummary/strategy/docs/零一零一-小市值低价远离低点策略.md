# 零一零一-小市值低价远离低点

**作者**: 零一零一

## 策略思路

此功略的核心不是“找最便宜的股票”，而是：
在小市值股票池里，优先选择市值更小、价格偏低、但没有贴近阶段低点的股票，用较短周期做轮动。
更准确地说，它是一套“小市值主因子 + 远离低点风控 + 低价约束 + 市值上限 + 异常形态过滤”的策略。

代表升序排序，即市值越小，排名越靠前。
策略的收益核心不是复杂多因子，而是小市值风格暴露。A 股历史上，小市值股票在流动性宽松、风险偏好恢复、题材扩散阶段，往往有很强的弹性。
但小市值不是免费午餐。它的问题也很明显：
容易遇到流动性不足。
