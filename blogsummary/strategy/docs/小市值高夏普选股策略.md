# 小市值高夏普选股策略

**帖子**: https://bbs.quantclass.cn/topic/index?id=77318  
**作者**: 未署名  
**发布时间**: 2026-04（选股策略再择时-2期）

---

## 一、策略概述

**核心逻辑**：小市值 + 低波动 + 超跌反弹

| 参数 | 值 |
|------|-----|
| 持仓周期 | 3天 |
| 选股数量 | 5只 |
| 回测区间 | 2009-01-01 ~ 2026-03-25 |

---

## 二、因子结构

| 因子 | 参数 | 权重 | 排序 | 投资逻辑 |
|------|------|------|------|----------|
| 振幅 | 90日 | **5** | 升序 | 选波动平稳的，降回撤风险 |
| 成交额缩波因子 | (10,60) | 1 | 升序 | 量能收缩=变盘前兆 |
| Ret | 5日 | 2 | 升序 | 选短期滞涨的，不追高 |
| 回撤 | 3日 | 1 | 降序 | 选近期抗跌的 |

**权重分布**：振幅占主导（5/9 = 56%），强调低波动。

---

## 三、过滤条件

| 条件 | 说明 |
|------|------|
| 月份 ≠ 1,4 | 日历效应，避开年报披露期 |
| 收盘价 3~40元 | 控制价格区间 |
| 市值分位 < 20% | 全市场最小20% |
| 光头阴线 > 1 | 形态过滤 |
| 剔除ST | 风险过滤 |

---

## 四、回测结果

| 指标 | 值 |
|------|-----|
| 年化收益 | **104.83%** |
| 最大回撤 | -53.61% |
| Calmar比 | 1.96 |
| 总手续费 | ￥34,319,230 |

**年度收益**：2015年最夸张（453%），2026年至今只有2%。

---

## 五、问题与缺陷

| 问题 | 说明 |
|------|------|
| 择时未启用 | 配置被注释，缺乏趋势判断 |
| 持仓过短 | 3天调仓，频繁交易侵蚀收益 |
| 选股集中 | 5只股票风险敞口大 |
| 缺乏基本面 | 仅技术面因子，无质量过滤 |
| 手续费高 | 3400万手续费说明换手极高 |

---

## 六、后续迭代方向

作者表示这是第一版，后续将持续迭代。潜在改进方向：

1. **延长持仓周期**：从3天延长到5~10天，降低换手
2. **增加择时模块**：启用布林带/MA等择时保护
3. **扩充选股数量**：从5只扩展到8~10只，分散风险
4. **加入基本面因子**：ROE、资产负债率等质量过滤
5. **优化日历效应**：用动态指标替代固定月份过滤

---

## 七、可取之处

| 点 | 说明 |
|----|------|
| 因子简洁 | 4个因子，逻辑清晰 |
| 权重分明 | 振幅权重最高，强调低波动 |
| 注释详细 | 每个因子都有投资逻辑说明 |
| 日历效应意识 | 知道避开1月4月风险期 |

---

## 八、注意事项

- 年化104%但回撤53%，属于高风险高收益型
- 手续费占比极高，实盘收益会大幅缩水
- 2015年贡献了大部分收益，其他年份表现平平
- 当前版本不择时，风控依赖不足
