# 基于小市值反转构建的选股策略

👤 作者：洋董

## 策略概述
- 四因子小市值反转策略：Ret(5)+成交额STD(5)+市值+换手率(5)，全部升序
- 3D短周期换仓，选股10只
- MA择时将回撤从55%砍到28%，收益几乎不变

## 附件信息
无

## 一、策略思路

**Ret(5)**：最近5个交易日收益率，升序排序，优先选择近5日涨幅较小甚至下跌的股票，体现短期反转思路，避免追高，倾向于寻找短线情绪降温后的标的。

**成交额STD(5)**：最近5个交易日成交额的标准差，升序排序，优先选择成交额波动较小的股票。这类股票短期资金扰动较弱，交易行为相对稳定，有助于降低组合的噪声暴露。

**市值**：升序排序，优先选择市值较小的股票。小市值股票通常具备更高的弹性和更强的风格溢价，但伴随更高波动，需与其他稳定性因子结合使用。

**换手率(5)**：最近5日平均换手率，升序排序，优先选择换手率较低的股票。策略更偏好交易不过热、筹码相对稳定的个股，回避短期资金博弈过于激烈的标的。

采用移动平均线择时可以显著降低回撤，收益从51.56%→51.51%，回撤从-55.34%→-27.82%。

## 三、策略配置（config.py）

```python
strategy = {
    'name': '小市值低换手率周频策略',
    'hold_period': '3D',
    'select_num': 10,
    "factor_list": [
        ('Ret', True, 5, 1),
        ('成交额STD', True, 5, 1),
        ('市值', True, None, 1),
        ('换手率', True, 5, 1),
    ],
    "filter_list": []
}
```

### 排序因子（全部升序）

| 因子 | 参数 | 逻辑 |
|------|------|------|
| Ret(5) | 5日收益率 | 短期反转，选近期跌幅大的 |
| 成交额STD(5) | 5日成交额标准差 | 选资金扰动小的，降低噪声暴露 |
| 市值 | 无 | 小市值溢价 |
| 换手率(5) | 5日均换手率 | 避开交易过热标的，筹码相对稳定 |

- 有择时年化：51.51%，回撤：-27.82%

## 五、总结

经典四因子小市值策略，逻辑透明，无未来函数风险。MA择时效果显著：回撤从55%砍到28%，收益几乎不动。38.99%胜率+2.49盈亏比，典型"亏小赚大"。缺点是最大连续亏损51周期，实盘心理压力大；2017-2018连续两年微亏，小市值风格弱势期表现一般。
