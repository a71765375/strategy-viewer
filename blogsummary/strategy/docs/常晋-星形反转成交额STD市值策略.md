# 常晋-星形反转成交额STD市值

**作者**: 常晋

## 策略思路

偏好 小市值 + 低成交额波动 + 非反转形态 的股票。这是一个偏向稳健小盘股的策略——剔除那些已经出现底部反转信号的股票（避免追涨），同时要求成交额稳定（排除异常放量/缩量），整体风格偏防御型小市值轮动。
回测时间：2009/01/01 - 2026/06/05

## 可取之处

年化59.77%，收益水平优秀。 Calmar 2.36表现良好。 小市值为核心因子，享受A股小盘溢价。 成交额类因子捕捉市场关注度变化，非热股选股思路。 反转/Ret类因子捕捉短期超跌反弹机会。 仅3个因子，思路简洁，过拟合风险相对较低。
