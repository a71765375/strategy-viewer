# 万家乐常卫全-442次多因子组合搜索

## 策略思路

背景 200多个因子里不知道怎么组合，手动试太慢。写了个自动化测试脚本，跑了442次回测，找到了一些规律，分享给大家。
197个因子按相似度归类→46个不重复因子
逐步添加法：从基础策略出发，每轮加1个最优因子，扩展到10轮
过滤排除法：16个弱因子逐个当排除条件
随机混合法：top20因子随机抽3-6个，跑50次
发现一：逐步添加的路径
成交额STD+小市值
流动性深度_20日
净主动买入强度_20日
成交额稳定性_20日
龙头股特征_60日
TRIX三重指数平滑_15日
流动性深度是最大增量（+0.16），5个因子是甜蜜点，之后反而变差。
发现二：因子加入优先级
按逐步测试的增量贡献排序：
流动性深度_20日
TRIX三重指数平滑_15日
净主动买入强度_20日
龙头股特征_60日
成交额稳定性_20日
已有基础因子的情况下，按这个顺序加，效果递减了就停。
发现三：过滤排除不如直接加因子
测试了16个过滤因子，最好的也只有+0.12提升，远不如直接加一个好因子。VaR/CVaR等风险指标做过滤反而有害。
发现四：随机组合效率低
随机50次最高比0.78，逐步添加法1.31。因子组合有方向，随机试不如按维度逐步加。
发现五：参数测试
STD窗口
流动性权重2倍
TRIX权重
因子不超过5个
