## 一、策略概述

**核心思路**：在小市值选股策略基础上，用**资金曲线自身的布林带**进行择时——净值跌破下轨空仓，站回中轨满仓。

**参数选择**：
- 布林带周期：10天（短周期，更敏感）
- 标准差倍数：0.8~1.5（窄通道，更易触发信号）

## 三、择时逻辑

### 3.1 布林带计算

```
中轨 MB = MA(N)  # N日移动平均
上轨 UB = MB + K × σ(N)  # K倍标准差
下轨 LB = MB - K × σ(N)
```

### 3.2 信号生成

```python
# 卖出信号：净值跌破下轨
condition_sell = (净值 < 下轨) & (净值.shift(1) >= 下轨.shift(1))
signals[condition_sell] = 0.0

# 买入信号：净值站回中轨
condition_buy = (净值 > 中轨) & (净值.shift(1) <= 中轨.shift(1))
signals[condition_buy] = 1.0

# 持续持仓
signals = signals.ffill().fillna(1)
```

### 3.3 为什么布林带有效？

1. **自适应性**：波动大时通道自动变宽，波动小时自动收窄
2. **均值回归**：价格围绕均值波动，极端偏离后倾向于回归
3. **风险预警**：2015年股灾期间，净值跌破下轨 → 及时空仓避险

## 四、参数扫描分析

作者对周期和标准差倍数进行了扫描，结论：

| 参数 | 推荐值 | 理由 |
|------|--------|------|
| 周期 N | 10天 | A股波动大，短周期更敏感；5天太抖，20天太慢 |
| 标准差倍数 K | 1.5 | 1.0倍假信号多，2.0倍反应慢，1.5倍平衡 |
