# 半岛微凉-小市值筛选因子

**作者**: 半岛微凉

## 策略思路

作为一个入学新生，目前在研究的基本都是小市值策略,所以发下我目前的筛选思路。
1、首先我将因子归为10个类别
市值、总市值对数、流通市值对数、平均市值
价格趋势与延续性
Ret、近期涨跌幅、TRIX、ROC变化率、月收益率、超额收益率
均值回归与超跌反弹
反转因子、均值回归ZScore、短期超跌程度、乖离率
价格波动与风险度量
历史波动率、Parkinson波动率、VaR、CVaR、最大回撤
资金流动与交易活跃度
换手率、MFI、OBV、Amihud非流动性、大单净买入比
价格与成交量的协同关系
量价相关系数、量价协同强度、VWAP偏离度
K线形态与技术指标信号
MACD、RSI、KDJ、布林带、均线排列、ADX
公司财务与经营质量
ROE、归母净利润同比增速
统计特征与市场微观结构
Beta、夏普比率、Hurst指数、自相关系数、筹码集中度
未明确归类的因子
是否在筛选候选范围
2、裸跑基准线
建立一个「无任何筛选」的基准回测结果，用于后续对比筛选因子的效果。
